# دليفريه

تطبيق العميل لمنصة توصيل تربط بين الأفراد والأنشطة التجارية ومندوبي التوصيل. هذه النسخة تبني تطبيق العميل والخادم الذي ستُبنى عليه لاحقًا تطبيق المندوب ولوحة الإدارة.

## ما الذي يعمل الآن

- دخول برقم موبايل مصري ورمز OTP، بدون كلمة مرور.
- حساب شخصي وحساب نشاط تجاري، مع حفظ عنوان المحل كاستلام افتراضي.
- طلب مندوب: استلام، تسليم، تفاصيل، وسيلة نقل، وسعر يحسبه الخادم.
- منع تكرار إنشاء الطلب بمفتاح Idempotency.
- متابعة الحالة، المحادثة، رمز التسليم، والتقييم.
- العناوين، الإشعارات داخل التطبيق، والدعم.
- أدوات تطوير منفصلة لمحاكاة المندوب، ولا تظهر إلا في نسخة debug ومع مفتاح بيئة التطوير.

## التشغيل

التفاصيل في [docs/SETUP.md](docs/SETUP.md).

```powershell
cd apps/api
copy .env.example .env
npm install
npm run db:embedded
npm run db:push
npm run db:seed
npm run dev
```

في طرفية أخرى، بعد تثبيت Flutter:

```powershell
cd apps/customer
flutter pub get
flutter run
```

في بيئة التطوير يظهر رمز OTP في رد الخادم وفي سجل الخادم. لا يُعاد الرمز عندما تكون `NODE_ENV=production`.
